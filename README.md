# Production-Grade DevOps Practice Project
FastAPI + React + AWS + Kubernetes + CI/CD

## Objective

This project simulates a real production system with intentional failures,
incident debugging, infrastructure automation, security scanning, and
blue-green deployment strategies.

The focus is DevOps mastery, not feature development.

---

## Tech Stack

Backend: FastAPI  
Frontend: ReactJS  
CI/CD: Jenkins  
Containerization: Docker  
Orchestration: Kubernetes  
Infrastructure: Terraform  
Cloud: AWS  
Security: SonarQube, Trivy  
Automation: Bash  
Monitoring: Basic logs & health checks  

---

## Learning Approach

- Every deployment includes intentional failures
- Every failure is documented
- Every fix goes through Pull Request
- No direct pushes to main
- Incident branches simulate production outages
